# Escape Flower

Unity UI project with Main (Combat) and Main Buy Gear screens built from individual Figma sprites.

## Open the project

1. Open this folder in Unity Hub with **Unity 6000.0.68f1**.
2. Open `Assets/Scenes/FlowerEscape.unity`.
3. Press Play. Use **START** to switch from Buy Gear to Main.

The reusable UI prefab is `Assets/Prefabs/UI/FlowerEscapeUI.prefab`.
`Assets/Scripts/FlowerEscapeResponsive.cs` controls the responsive layout.

This project implements UI presentation; gameplay and advertising services are not implemented.

`Evidence/` contains historical captures and comparisons. Older captures and the original status report may predate subsequent layout adjustments.

Unity caches and generated IDE files are excluded from version control. Unity restores packages and rebuilds its Library when the project is opened.
